# 2단계: 세금 시뮬레이션 엔진

이 단계는 분류·검증된 과세 원자료를 이용한 추정 엔진입니다. 최종 신고세액, 평가자산 매도세금,
절세 추천, 연금 수령세금 및 UI는 포함하지 않습니다. 기존 스키마 버전 1과 호환됩니다.

## 계산 계약

| 계산 | 입력 및 계산 단위 | 기본 시나리오 |
|---|---|---|
| 미국주식 양도 | 납세자 전체 일반계좌의 해당 연도 실현 과세 손익 | `max(연간 순손익 - 2,500,000, 0) × 0.22` |
| 국내 일반 배당 | 총액과 실제 원천징수 또는 명시적 기본세율 가정 | 실제액 우선, 미입력 시 0.154 가정 |
| 미국 배당 | 실제 해외 원천징수액 또는 명시적 해외세율, 실제 국내 원천징수액 | 해외 15%를 자동 적용하지 않음 |
| ISA | 한 계좌의 개설부터 정산 가정일·해지일까지 적격 산입액과 손실 | 일반형 200만원, 서민형·농어민형 400만원 공제 후 0.099 |
| 금융소득 알림 | 일반계좌의 종합과세 대상 금융소득 산입액 | 2,000만원 **초과** 시 True |

통화 변환, 취득원가, 매수·매도 수수료 및 필요경비를 반영해 확정한 **정수 KRW** 과세 손익을 받습니다.
현재가나 평균매수가로 세금 취득원가를 추정하지 않습니다. 수수료는 엔진이 다시 차감하지 않습니다.
손익에는 정수, 세율에는 Decimal을 사용합니다. 합산세율 적용 후 원 미만 절사는 시뮬레이션 규칙입니다.
국세·지방세의 신고·납부 단수처리와 동일하다는 보장은 하지 않습니다.

## 모델 및 사용

순수 계산기는 `CapitalGainsInput`, `DividendInput`, `ISAInput`, `FinancialIncomeInput`을 받습니다.
결과도 Pydantic 모델이며 `model_dump_json()`으로 변환할 수 있습니다.

```python
from money_manager.tax_calculators import CapitalGainsInput, calculate_us_stock_tax

result = calculate_us_stock_tax(
    CapitalGainsInput(realized_gains_krw=(10_000_000, -2_000_000))
)
assert result.estimated_tax_krw == 1_210_000
```

DB 기반 계산은 `TaxEngine(connection).annual(AnnualTaxRequest(...))` 및
`.isa_contract(ISAContractRequest(...))`를 호출합니다. 엔진은 읽기 스냅샷을 사용하며
상위 트랜잭션을 커밋하거나 원자료를 수정하지 않습니다.

`demo.py`에는 거래와 연결된 `TaxEvent` 적재 예시가 있습니다. `basis_source`에는 실거래의 경우
증권사 과세자료·취득원가 계산 근거를 기록하세요. `taxable_income_krw=None`은 0원이 아니라 미확정입니다.
기본값의 원천징수액 0은 실제 0원임을 확인한 이벤트에만 사용해야 합니다.
실제 해외 배당 자료를 임의의 15% 계산으로 대체하지 마세요.

## 자료 누락과 경고

- 거래의 `recognized_on`으로 귀속연도를 정하고 `TaxEvent` 연결을 확인합니다.
- 양도 과세자료 누락은 미국 양도세 결과를 `None`으로 만듭니다. 금융소득 자료 누락은 알림 판단을 미확정으로 만듭니다.
- 완전성이 미확인이고 알려진 소득이 기준금액 이하면 알림은 `None`입니다. 알려진 금액만으로 이미 초과하면 `True`입니다.
- `data_coverage_confirmed=True`는 외부 은행·다른 증권사까지 사용자가 완전성을 확인했다는 선언입니다.
- 결과의 `issues`에 `WARNING`과 `BLOCKER`를 기록합니다. `report.needs_review`는 계산을 막는 사유가 있는지 나타냅니다.
- `TaxPolicy`의 유효기간은 연간 계산의 전체 연도, ISA 계산의 정산 가정일을 포함해야 합니다.
- DRAFT/SCENARIO 정책은 경고를 표시합니다. VERIFIED도 계산 범위와 누락 경고를 생략하지 않습니다.

## 세무 범위를 잘못 합치지 않기 위한 처리

한국 거주자이며 미국 세법상 납세자가 아닌 경우를 지원합니다. 비거주자, 미국 시민권·영주권 등 이중 납세,
단기 외국인 거주자의 국외소득 범위, 법인 과세는 별도 모델링이 필요합니다.

일반계좌의 비과세 국내 상장주식 매매손실은 미국주식 양도손익에 합치지 않습니다.
과세 국내주식이 있으면 공유 기본공제·혼합세율 처리가 필요하므로 미국 부분만 확정하지 않고 막습니다.
국내 상장 해외자산 ETF의 매도 과세는 `FINANCIAL_INCOME` 산입액을 사용합니다.
경제적 차익과 과표기준가에 따른 산입액을 같은 값으로 자동 취급하지 않습니다.

ISA는 연도별 비과세 한도를 반복 적용하지 않습니다. 국내 직접주식 비과세 차익은 제외하고,
적격 직접주식 손실과 국내주식형 ETF의 제외 손실을 구분합니다. 증권사 확정 자료의 산입액을 사용하며,
자산별 상세 손실 배분 순서·외국납부세액 조정은 구현하지 않았습니다.
유지요건 전의 개설 중 계좌는 요건 충족 후 정산한다는 가정으로 표시합니다.
실제 3년 미만 해지는 예외·추징 판정 없이 특례세액을 제시하지 않습니다.
윤일 개설 계좌의 3년 날짜는 이 데모에서 해당 연도 마지막 2월 날짜로 조정합니다.
실제 금융기관 정산의 만기 판정은 계약정보와 함께 확인해야 합니다.

ISA·연금저축·IRP 소득은 일반계좌 금융소득 집계와 분리합니다. 연금 납입 세액공제·수령세금은 미구현입니다.
고배당기업 분리과세 배당은 적격성 및 신청이 원자료에서 확인된 `SEPARATE_DIVIDEND`만 기준금액에서 제외합니다.
별도 누진 세액을 계산하지 않으며 모든 국내 배당에 자동 적용하지 않습니다.
기준금액 이하 알림은 신고의무 없음이라는 뜻이 아닙니다. 국내 미원천징수 국외 금융소득 등은 별도 검토 대상입니다.
배당의 `net_cash_krw`는 원천징수 후 현금이며 최종 종합과세·외국납부세액공제 후 실수령액이 아닙니다.
